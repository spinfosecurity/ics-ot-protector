ICS OT Protector

TCP reachability scanners for water, energy, building automation, and rail. Shared config, preflight checks, JSON reports with severity and remediation notes, plus a small CLI to review results offline. No credential tests, no exploit payloads.

  • Water & wastewater WUP · CISA water-sector guidance alignment
  • Power grid & substation EGP · DNP3, IEC protocols, vendor CVE ports
  • Building automation BAS Guardian · BACnet / BMS exposure review
  • Rail & transit ROP · remote access and ICS protocol checks
  • Defensive scope

    Written for authorized assessments. Limits and safe-operation docs are in the repo.

  • Readable reports

    JSON findings with severity and remediation fields — meant for IT/OT handoff, not raw port dumps.

  • Tested code

    Shared modules, sector configs, Bash + Pester tests, GitHub Actions on every push.

Common questions

Is this offensive security?

No. TCP connect checks on authorized networks. Not a pentest tool, exploit framework, or cred tester.

What sectors does it cover?

Water, power grid/substation, building automation (BACnet/BMS), and rail — each with its own port catalog.

Authorized use only. Do not scan systems without permission from the asset owner.
