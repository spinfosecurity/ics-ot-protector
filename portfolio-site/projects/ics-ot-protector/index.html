ICS OT Protector

OT/SCADA exposure checks for water, energy, building automation, and rail. PowerShell and Bash, TCP reachability on authorized networks, JSON reports you can review offline.

Source on GitHub Quick start

Sectors

Older standalone repos are archived; everything lives here now.

  • Water & wastewater (WUP) Interactive and scan mode; CISA water-sector oriented checks
  • Power grid & substation (EGP) CLI subnet scans; DNP3, IEC protocols, vendor CVE ports
  • Building automation (BAS Guardian) BACnet/BMS-oriented exposure review
  • Rail & transit (ROP) Remote-access and ICS protocol exposure checks

What it does

  • Scans authorized IPv4 subnets for reachable remote-access and OT/ICS-related TCP ports
  • Labels findings by severity, remediation priority, owner role, and recommended action
  • Emits JSON reports with sector metadata, summary statistics, and optional CSV export
  • Supports offline triage via review_scan_report.sh and Review-ScanReport.ps1
  • Points operators to public CISA/ICS-oriented remediation guidance in-repo

An open port is a lead to investigate, not proof of compromise. These tools do not test credentials, run exploits, or replace a full pentest. IPv6 is not supported yet.
