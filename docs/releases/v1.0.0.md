# Water Utility Protector v1.0.0

> Copy these notes into GitHub when manually creating the `v1.0.0` release.

## Overview

Water Utility Protector is a free PowerShell and Bash tool for **authorized** water and wastewater OT/SCADA exposure discovery. It helps defenders identify reachable remote-access services and selected industrial protocol ports from an approved scan host.

## Included

- PowerShell and Bash implementations for Windows, Linux, and macOS environments.
- Checks for approved TCP exposure candidates, including RDP, VNC, SSH, EtherNet/IP, Modbus TCP, S7, DNP3, and BACnet/IP.
- Local reporting designed for engineering and security triage.
- Safe-operation guidance, threat-model documentation, and a synthetic sample report.
- GitHub Actions validation for PowerShell parsing/linting, Bash syntax, and non-networked repository checks.

## Important safety boundary

This tool is for authorized defensive assessment only. It does not attempt credential testing, authentication bypass, exploitation, configuration changes, or device commands. Coordinate with plant operations and stop immediately if instability or unexpected behavior occurs.

## Known limitations

- TCP reachability is an exposure signal, not proof of device identity, vulnerability, or compromise.
- Firewalls, routing, NAT, and host controls can cause false positives or false negatives.
- This release does not provide compliance certification, continuous monitoring, malware detection, or attribution.
- Validate every finding with the responsible engineering and security teams before operational action.

## Validation

The repository includes non-networked tests that parse source and validate documentation. The tests do not execute scanners, contact devices, send network traffic, or attempt authentication.

## Next steps

Future work includes report-schema improvements, configurable scan profiles, safe fixture-based unit coverage, and examples for SIEM and ITSM ingestion.

## Upgrade guidance

This is the initial public version. Review `docs/safe-operation.md`, confirm written authorization and scope, and test first on the smallest approved target set.
