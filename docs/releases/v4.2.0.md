# Release v4.2.0 — Shared Scan Engine, Pre-flight, Summary & CSV

**Date:** 2026-08-23

## Highlights

- **Shared TCP scan engine** for Bash and PowerShell — all four sectors use the same host×port probing pipeline in scan mode
- **Non-interactive scan mode** — `./scripts/ics-ot-protector.sh scan …` and `.\scripts\ics-ot-protector.ps1 -Scan …`
- **Pre-flight scope validation** — dependency checks, CIDR validation, host-count limits; `--force` / `-Force` for large scopes
- **Report summary + CSV** — `metadata.summary` in JSON exports; companion CSV in scan mode (disable with `--no-csv` / `-NoCsv`)
- **Fixture-based integration tests** — mock TCP listener exercises engine, export, and summary/CSV paths

## Upgrade notes

- Interactive sector scanners (WUP WUP, BAS Guardian) are unchanged; use **scan mode** for unified reporting with summary and CSV.
- Large subnets (/16 and broader) and scopes above 4096 unique hosts require explicit `--force` / `-Force`.
- Bash scan mode requires `jq` and `timeout` (coreutils).
