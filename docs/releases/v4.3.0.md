# Release v4.3.0 — Config Overlays, Progress/ETA, Interactive Parity

**Date:** 2026-08-23

## Highlights

- **`--config` / `-Config`** — merge YAML or JSON port-profile overlays onto sector config at runtime
- **Scan progress + ETA** — shared progress hooks with hosts/sec and estimated time remaining
- **Interactive parity** — WUP WUP and BAS Guardian use preflight, `metadata.summary`, and CSV export (when enabled)
- **BAS performance** — default concurrency raised to 50 threads (matching WUP)

## Upgrade notes

- Overlays merge onto compiled `config/sectors/*.json`; base YAML does not need editing for site-specific ports.
- Scan mode shows progress by default; pass `--quiet` / `-Quiet` to suppress.
- Interactive export now writes the same summary block as scan mode when JSON export is enabled.
