# Release v4.4.0 — Remediation Metadata & Offline Report Review

**Date:** 2026-08-23

## Highlights

- **Structured remediation metadata** — findings include `RemediationPriority`, `RemediationAction`, and `OwnerRole` for triage handoff
- **Extended summaries** — `metadata.summary` adds breakdowns by category, priority, owner role, and `top_hosts`
- **Offline report review** — `scripts/review_scan_report.sh` and `scripts/Review-ScanReport.ps1` for post-scan triage without re-running scanners
- **CSV enrichment** — companion CSV exports include remediation columns when present

## Upgrade notes

- JSON schema remains `1.0`; new finding fields are backward-compatible additions.
- Existing reports without remediation fields are enriched at export time from severity/category heuristics.
- SIEM/ticketing ingestion examples remain deferred per roadmap.
