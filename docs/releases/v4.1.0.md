# Release v4.1.0 — Unified JSON Export & Launcher

**Date:** 2026-08-19

## Highlights

- All sector scanners export findings as **JSON** (`schema_version` 1.0)
- **Unified launcher:** `./scripts/ics-ot-protector.sh <sector>` / `.\scripts\ics-ot-protector.ps1 -Sector <sector>`
- Shared export module in `scanners/_shared/`
- Documentation split into shared baseline + sector addenda

## Upgrade notes

- Text and CSV report files are no longer generated. Use the JSON export (`*-results-*.json`).
- Report field names are normalized: `Host`, `Category`, `Description`, `Remediation`.
- WUP/BAS interactive scanners prompt for JSON export instead of text.
